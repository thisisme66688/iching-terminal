# ☯️ 現代易經運算終端 (Modern I Ching Terminal)

> 結合三千年《易經》古老智慧與現代 UI/UX 設計的網頁版戰略決策系統。

**現代易經運算終端** 是一款免安裝、純前端運行的卜卦網頁應用。本專案將傳統晦澀難懂的算命術語，轉化為現代商業、職場、人際關係的戰略決策指南。透過 3D 擬真物理拋擲與量化數據面板，提供兼具視覺美感與實用價值的沉浸式占卜體驗。

## ✨ 核心功能 (Features)

*   🪙 **3D 擬真硬幣拋擲**：使用純 CSS 3D 構建具有正反面（康熙通寶 / 滿文書法）的立體銅錢，並結合 JS 亂數運算每次落地的物理翻轉結果。
*   📊 **多維度數據量化**：獨創卦象數值化系統，透過「成功率、幸運度、風險值、主動度」四個動態進度條，直觀呈現當前局勢的能量分佈。
*   📖 **完整 64 卦資料庫**：內建周文王 64 卦與 384 爻完整邏輯，將古典爻辭重新編譯為「現代決策、風險管理與專案執行」的白話建議。
*   ⚠️ **動態變數警告系統 (動爻解析)**：精準捕捉卜卦過程中的「老陰、老陽」（變卦），並以醒目的 UI 呈現不同階段的突發事件預警與對策。
*   📱 **響應式科技感介面**：採用暗色系 (Dark Mode) 搭配燙金點綴，融合道教太極符號與現代終端機風格，支援手機與電腦版完美顯示。

## 🛠️ 技術棧 (Tech Stack)

本專案採用純前端原生技術開發，無依賴任何外部框架或資料庫，極度輕量且載入迅速：

*   **HTML5**：語意化結構與內嵌 SVG 繪製銅錢圖案。
*   **CSS3**：Flexbox 排版、`transform-style: preserve-3d` 建立 3D 空間、CSS Keyframes 動畫。
*   **Vanilla JavaScript (ES6+)**：DOM 操作、陣列資料查詢、隨機數生成與運算邏輯控制。

---

## 🎲 運算邏輯 (Divination Logic)

本系統嚴格遵循傳統「金錢卦」的起卦邏輯，透過拋擲 3 枚銅錢 6 次，由下而上生成本卦與動爻：

*   **3 個反面 (滿文)**：老陰 (變) ➔ 顯示陰爻 ❌
*   **2 個反面 + 1 個正面**：少陽 ➔ 顯示陽爻
*   **1 個反面 + 2 個正面**：少陰 ➔ 顯示陰爻
*   **3 個正面 (漢字)**：老陽 (變) ➔ 顯示陽爻 ❌

*(註：觸發變爻時，系統將自動提取對應階段的警告事件並顯示於結果面板)*
